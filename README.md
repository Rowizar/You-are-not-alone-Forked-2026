## Как запустить проект

1. Скачать **Ren'Py SDK 8.5.3** с [renpy.org](https://www.renpy.org/latest.html) и распаковать в любую папку (например, `Downloads/renpy-8.5.3-sdk/`).
2. Склонировать репозиторий или скачать ZIP.
3. Запустить Ren'Py launcher (`renpy.exe` в корне SDK).
4. В launcher указать «Projects Directory» — **родительскую** папку, в которой лежит этот репозиторий, **либо** через «Preferences» → «Projects Directory» поменять путь. После этого в списке слева появится проект «Youarenotalone».
5. Выбрать проект → нажать **Launch Project**.

### Сборка дистрибутива

В launcher → **Build Distributions**. Конфигурация в [project.json](project.json) — по умолчанию собирается только под PC.

### Отладка

В Ren'Py SDK режим разработчика включён по умолчанию, поэтому в игре работают:

- `Shift+O` — консоль (можно вводить `jump <метка>`, менять переменные)
- `Shift+D` — меню разработчика
- `Shift+R` — релоад скриптов без перезапуска игры
- `Ctrl` (удерживать) — быстрый skip уже прочитанного текста
